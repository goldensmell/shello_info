📋 개요

Shello(이하 "앱")는 사용자의 자산·수입·지출을 관리하는 개인 재무 관리 앱입니다.

본 방침은 앱이 사용자의 정보를 어떻게 수집·이용·보호하는지 안내합니다. Shello를 사용함으로써 본 방침에 동의한 것으로 간주됩니다.

✅ Shello는 사용자의 금융 데이터를 외부 서버로 전송하지 않습니다.

✅ 모든 데이터는 사용자의 기기와 iCloud에만 저장됩니다.

✅ 광고, 마케팅 목적의 정보 수집이 없습니다.

📥 수집하는 정보

Shello는 사용자가 앱에 직접 입력한 재무 데이터만 사용합니다. 앱이 자동으로 수집하는 개인정보는 없습니다.

사용자가 직접 입력하는 데이터:

  • 자산 정보 (금융자산·부동산·부채 등 금액 및 카테고리)
  • 월 수입 정보 (실수령액·상여·기타 소득)
  • 월 지출 정보 (고정지출·변동지출 합계)
  • 재무 목표 (목표 금액·목표 유형·목표 기간)
  • 메모 (선택 입력 사항)

⚠️ 위 데이터는 모두 사용자가 직접 입력하는 정보입니다.

앱은 금융기관·증권사·은행 등 외부 기관과 자동 연동되지 않습니다.

🔒 데이터 저장 및 보호

입력된 모든 재무 데이터는 사용자의 기기 내 로컬 저장소에 저장됩니다.

✅ 외부 서버로 전송되는 데이터 없음

✅ 제3자에게 판매·공유·제공되는 데이터 없음

✅ 광고 목적 데이터 수집 없음

iCloud 백업:

사용자가 iCloud 백업을 활성화한 경우, 앱 데이터가 Apple의 iCloud에 백업될 수 있습니다. iCloud 백업은 Apple의 개인정보처리방침을 따르며, Shello는 iCloud에 저장된 데이터에 접근하지 않습니다.

iCloud 백업 설정은 기기의 설정 앱에서 언제든지 변경할 수 있습니다.

🏦 금융기관 연동 없음

Shello는 다음 서비스와 연동되지 않습니다.

  • 오픈뱅킹 서비스
  • 은행·카드사 API
  • 증권사·보험사 API
  • 간편결제 서비스
  • 기타 금융기관 자동 연동 서비스

모든 자산·수입·지출 정보는 사용자가 직접 입력해야 합니다.

📊 투자 조언 미제공

⚠️ Shello는 투자 조언, 금융 상품 추천, 자산 운용 조언을 제공하지 않습니다.

앱에서 제공되는 모든 수치(순자산·달성률·예상 기간 등)는 사용자가 입력한 값을 기반으로 계산된 참고용 정보이며, 실제 세금·수수료·시장 변동을 반영하지 않습니다.

재무적 의사결정은 전문 재무설계사 또는 금융 전문가와 상담하시기를 권장합니다.

🔔 알림

Shello는 월 결산을 위한 알림을 발송할 수 있습니다. 알림 기능을 사용하려면 앱 설치 후 알림 권한을 허용해야 합니다.

  • 알림은 사용자가 설정한 날짜·시간에만 발송됩니다.
  • 알림 내용에 개인 재무 정보가 포함되지 않습니다.
  • 알림 수신을 원하지 않으면 앱 설정 또는 기기 설정에서 언제든지 비활성화할 수 있습니다.
📱 앱 사용 정보

Shello는 별도의 사용자 행동 분석·추적 SDK를 사용하지 않습니다.

다만, Apple App Store를 통한 다운로드·충돌 리포트 등 Apple이 기본적으로 수집하는 정보는 Apple의 개인정보처리방침을 따릅니다.

👶 아동 개인정보 보호

Shello는 만 14세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만 사용자는 법정대리인의 동의가 필요합니다.
